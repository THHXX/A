查看（Read）
GET /api/projects/:id
读取该项目的种子、图谱、人设、报告与对话历史，渲染项目详情视图
📝
写入（Write）
POST /api/projects/:id/data
仿真过程持续追加日志、更新人设状态、保存生成的报告章节
♻️
复用（Reuse）
POST /api/projects/:id/clone
复用历史图谱与人设作为新项目起点，避免重复 5 分钟图谱构建
🗑️
删除（Delete）
DELETE /api/projects/:id
二次确认后整体清理 /data/{user_id}/{project_id}/ 目录
📌 核心规则：所有 CRUD 路径强制带上 {user_id}/{project_id} 二级前缀， 系统层面保证 跨用户 0 数据泄露 与 跨项目 0 数据交叉污染
