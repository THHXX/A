02 / BACKGROUND

为什么需要 群体智能预测？

传统预测的局限正在被群体涌现的力量打破。

// 传统预测的困境

专家拍脑袋 · 模型黑箱

  • 统计模型只输出"结果"，无法展示"过程"
  • 群体行为高度耦合，传统建模难以刻画
  • 专家经验主观，假设无法低成本回测
  • "上帝视角"变量注入，几乎不可能
VS

// MiroFish 的方案

多 Agent · 群体涌现 · 平行世界

  • 百万级智能体在数字沙盘中自由互动演化
  • GraphRAG + 长期记忆，让每个 Agent 拥有"灵魂"
  • 自然语言注入"上帝视角"，零风险预演决策
  • 不仅给结论，还能复盘事件传播全过程

05 / FUNCTIONAL REQUIREMENTS

功能需求 — 六字口诀

传图 · 设人 · 跑模 · 出报 · 聊天 · 存档
FR-01
知识图谱构建
「 传 · 图 」
用户上传 PDF / TXT / MD 种子材料，系统于 5 分钟内完成实体抽取、关系识别，生成可视化知识图谱。
FR-02
数字人设生成
「 设 · 人 」
基于群体特征自动生成具备背景、性格、记忆的虚拟智能体，规模可达 100 ~ 5000，支持预览与重生成。
FR-03
双平台并行仿真
「 跑 · 模 」
支持 Twitter / Reddit 双平台行为模拟，可设置轮数并以"上帝视角"动态注入外部变量。
FR-04
预测报告生成
「 出 · 报 」
ReportAgent 调用工具集与模拟后环境深度交互，产出结构化预测报告：趋势、关键事件、观点分布。
FR-05
深度交互对话
「 聊 · 天 」
用户可与模拟世界中任意 Agent 自然语言对话，亦可与 ReportAgent 追问报告细节。
FR-06
历史项目管理
「 存 · 档 」
查看、复用、删除历史项目，每个项目独立存储种子材料、图谱、人设、报告与对话。

08 / KNOWLEDGE GRAPH

知识图谱 · 从种子到平行世界的入口

百万级实体关系，可视化呈现

从一段文字、一份报告出发，MiroFish 自动构建包含人物、事件、机构、观点的多层知识图谱， 为后续 Agent 人设生成提供"世界观"基底。

  • 支持 PDF / Markdown / 纯文本多格式输入
  • 实体-关系-属性三元组自动抽取
  • 节点详情面板可查看属性、关联与摘要
  • 支持图谱级别过滤、关系权重调整
MIROFISH · 知识图谱 08 / 13
09 / REPORT GENERATION

预测报告 · ReportAgent 自主写作

从大纲规划到分章撰写，全程自治

仿真结束后，ReportAgent 自动调用 14 项工具与模拟后环境深度交互， 完成大纲规划、分章节撰写、实时控制台输出。

  • 自动生成结构化大纲（4 ~ 6 章节）
  • 每章独立调用工具检索仿真数据
  • 支持长达 23 分钟的深度推理生成
  • 章节可点击溯源，结果可信可追溯
